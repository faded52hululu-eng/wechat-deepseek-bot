# DeepSeek 微信聊天助手

Windows 本地运行，通过 RapidOCR 读取普通微信独立聊天窗口的文字气泡，结合可见上下文调用 DeepSeek，支持预览与自动回复。电脑需保持开机、微信登录、桌面解锁且目标窗口可见。

## 快速开始

从仓库页面选择 **Code → Download ZIP**，或用 Git 克隆项目，然后完整解压到一个目录。此项目是 Python 源码，需要安装依赖，不能只下载一个启动脚本。

## 安装和使用

1. 安装 Python 3.10+ 64 位（建议 3.11/3.12），勾选加入 PATH。
2. 解压整个项目到本地目录，双击 `setup.cmd` 安装依赖。需要访问 GitHub 和 PyPI。
3. 双击 `start.cmd`。填写自己的目标群名或联系人备注名、群昵称和 DeepSeek API Key，保存设置。
4. 在微信双击目标会话，打开独立窗口，滚动到底部。让助手与微信并排，避免遮挡。
5. 依次框选完整气泡区和空白输入区。气泡区排除标题、头像、输入框；输入区排除工具栏、发送按钮。窗口重开、缩放后重新校准。
6. 先运行“检测读取（30秒）”，确认新来信与自己消息区分正确。再以“预览回复”启动，检查拟回复。
7. 确认效果后，停止并选择“自动回复”，重新启动。程序将使用当前登录微信号发送消息，会占用鼠标、键盘与剪贴板。

## 回复策略

默认不要求 @，保留最多 60 条内存上下文。新消息安静 2 秒后判断，持续聊天最长等 45 秒；模型可以选择沉默。默认两次回复尝试至少间隔 180 秒，每小时最多 6 条，可在面板调整。启动前的可见消息仅作背景，不补答历史。

预览同样调用 DeepSeek 并产生 API 费用。可用环境变量 `DEEPSEEK_API_KEY` 配置 Key；面板留空即可。对话接口固定为 DeepSeek 官方地址，默认模型为 `deepseek-flash`，可在面板修改。

## 读取和发送限制

OCR 仅面向常规文字气泡，可能有错字、漏读；不理解图片、语音和视频，不保证识别每位群成员昵称。完全变化且没有可靠旧气泡的新画面作为背景；像素完全相同的重复消息可能无法区分。窗口被遮挡时暂停等待恢复，请勿向上翻历史或同时手动编辑输入框。

默认使用本地 RapidOCR，模型在进程内复用。环境变量 `WECHAT_OCR_ENGINE=windows` 可启用 Windows OCR 备用路径。启动日志显示“OCR 图像跟踪 v3”。

输入框有草稿、窗口身份或焦点异常时不会继续发送。发送不确定或失败时切换为本轮预览模式，不自动重试。灰色语音提示有专门过滤；仍请检查输入框区域是否校准正确。“已尝试发送”不代表收到送达回执。

## 常见问题

**程序没有读到新消息？** 先确认微信独立窗口没有被遮挡，窗口大小和标题未变，消息已滚动到底部，再运行“检测读取（30秒）”。日志中的气泡数与可读文字数能帮助区分没有文字、OCR 漏读和限流等待。刚启动时已有的消息不会触发回复。

**预览正常，自动回复没有发出？** 检查输入区校准、草稿、目标窗口焦点以及发送快捷键（当前使用 Alt+S）。发生发送错误后，本轮会转为预览模式；处理原因后停止并重新启动，不会自动重发。

**群聊不 @也能接话吗？** 可以，模型结合上下文判断是否发言；冷却时间与每小时上限仍生效。群昵称用于帮助辨认别人是否在呼唤机器人，并非必须 @。

**更新后仍显示旧版本？** 完整关闭助手面板后重新打开 `start.cmd`。依赖有变化时先运行 `setup.cmd`。

## 本地数据与再次分享

本分享包不含 API Key、真实群名、联系人、窗口句柄、聊天截图、诊断日志或运行状态，也不包含虚拟环境和第三方源码。`config.example.json` 是空白示例；面板首次保存会生成自己的 `config.json`。

运行后可能生成敏感文件：`config.json`（Key 明文）、`ocr_calibration.json`（窗口信息）、`diagnostics/`（错误截图与日志）、`*rate_state.json`（频率状态）。这些路径已加入 `.gitignore`，但手动压缩时仍需自行排除。上下文保存在内存中；预览或回复时相关上下文会发送给 DeepSeek，请提前告知群友。

## 验证和来源

43 项离线测试覆盖消息跟踪、滚动、重复消息、输入草稿保护、异常恢复与限流。使用 `python -m unittest discover -p "test_*.py"` 运行。离线验证不保证各微信版本长期稳定，客户端升级后需重新实测。

- RapidOCR：https://github.com/RapidAI/RapidOCR
- pywechat：https://github.com/Hello-Mr-Crab/pywechat
- DeepSeek API：https://api-docs.deepseek.com/zh-cn/

安装脚本获取固定版本的 pywechat 及其许可证至 `upstream/`；当前默认使用 OCR，保留旧 UI 适配代码。分享包不包含第三方源码或模型，依赖在安装时获取。

## 项目文件

| 文件 | 作用 |
| --- | --- |
| `start.cmd` / `panel.py` | 启动脚本与本地设置面板 |
| `setup.cmd` / `setup.ps1` / `install_deps.py` | 创建虚拟环境并安装依赖 |
| `runner.py` / `core.py` | 模型调用、上下文与频率策略 |
| `ocr_adapter.py` / `ocr_messages.py` / `rapid_engine.py` | OCR、气泡跟踪与发送控制 |
| `ocr_test.cmd` / `OCR测试说明.md` | 不调用 API、不发消息的读取测试 |
| `config.example.json` | 无个人信息的默认配置示例 |
| `test_*.py` | 离线回归测试 |

该工具为非官方本地实验项目。普通微信客户端的界面、主题和缩放变化可能影响识别，需要在自己的环境中先测试。
